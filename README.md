# vulu Launcher

<img width="128" height="128" alt="vulu Launcher" src="https://github.com/user-attachments/assets/8566a06d-6fe5-4a4e-aeb1-e812ab9e67b7" />

A private Minecraft launcher for me and my friends. Accounts are invite-only: you can
request one from the login screen and an admin approves it.

## Install

Download `vulu-launcher-setup.exe` from the [latest release](https://github.com/vuluvulu1/vulu-launcher/releases/latest) and run it.
The setup downloads the newest version and creates shortcuts. After that the launcher
updates itself on every start, and it can be removed from Windows' "Apps" list.

Windows may show a SmartScreen warning the first time: *More info → Run anyway*.

## Features

- Vanilla and your own instances (Fabric, Quilt, Forge, NeoForge), with Java downloaded automatically
- Modrinth browser for mods, resource packs, shaders and modpacks
- **vulu Packs**: modpacks shared by the group, installed and updated in one click
- Profiles and a community list
- Three themes: Classic, Neon and Atlas
